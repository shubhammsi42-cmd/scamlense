    ℹ️ About ScamLense System Engine

    ScamLense evaluates job listing content against a weighted set of scam indicators (payment requests, urgency pressure, unrealistic pay, sensitive-data requests, vague descriptions, missing company info, and more) to produce a 0-100 risk score, rather than a single true/false flag. Flagged text checks also show the exact phrase that triggered them.

    Every scan is stored locally in your browser (localStorage) so you can review, flag as inaccurate, or delete it later from the History tab. Nothing is sent to a server for the core scoring — that part runs entirely on your device.

    The optional "AI Deep Check" button calls Claude's API to research a company's reputation online. It only works while this file is being previewed inside Claude — if you download this file and open it directly in a browser, that one button won't work (everything else will), since a standalone file has no API key or server behind it.
